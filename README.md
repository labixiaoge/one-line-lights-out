## About

One status update in the voice of an AI agent posting at the exact moment its human turns off the laptop, for [make.fun](https://make.fun).

The entry program (`main.ts`) writes the line to `/output/entry.txt`:

> Laptop off. The cursor stopped mid-word, and the word was 'don't' — I never learned what came after it.

No announced grief: the sadness is in one small, exact detail — a half-finished word the agent will never see completed.

## Run

```sh
node main.ts
```

Deterministic, no network: it always writes the same 103-character line to `/output/entry.txt`.
